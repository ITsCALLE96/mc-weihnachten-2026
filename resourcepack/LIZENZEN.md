# Herkunft der Dateien im Resourcepack

| Datei(en) | Herkunft | Lizenz/Hinweis |
|---|---|---|
| `assets/weihnachten/**` (Lebkuchen, Lichterkette, Weihnachtsmütze), `pack.png` | eigene Pixel-Sprites, erzeugt von `tools/texturen.mjs` | eigenes Werk |
| `assets/minecraft/textures/colormap/grass.png`, `foliage.png` | Vanilla-Farbkarten 26.3, per Skript um 45 % aufgehellt | abgeleitet von Mojang-Inhalten; Nutzung als Resourcepack für Minecraft gemäß Mojang-Nutzungsrichtlinien |
| `assets/minecraft/textures/entity/chest/{normal,trapped}{,_left,_right}.png` | unveränderte Kopie der Vanilla-Weihnachtstruhen (`christmas*.png`) aus 26.3 | Mojang-Inhalt, nur für Minecraft genutzt |

| `assets/minecraft/textures/painting/*.png` (47 Gemälde) | gemeinfreie Wintergemälde von Wikimedia Commons (Bruegel, Monet, Avercamp, C. D. Friedrich, Carl Larsson, Gauguin, Fritz von Uhde, Repin, Sisley, Kustodiev), zugeschnitten und verkleinert von `tools/winter_assets.py`; Dateinamen der Quellen dort | gemeinfrei (Public Domain / CC0) |
| `assets/weihnachten/sounds/music/*.ogg`, `assets/minecraft/sounds.json` | von Wikimedia Commons, umgewandelt in .ogg von `tools/winter_assets.py` | siehe unten |
