# Ohne Modpack spielen (normales Minecraft Java)

Das Modpack ist **freiwillig**. Mit normalem Minecraft Java spielst du genauso mit. Die Mods bringen Optik und Komfort, aber keinen Spielvorteil.

## So kommst du rein

1. **Im Discord anmelden** (Edition: Java, dein Minecraft-Name). Erst danach stehst du auf der Whitelist.
2. Im Minecraft Launcher die Version **26.3** starten. Eine andere Version kommt nicht auf den Server.
3. **Mehrspieler** → **Server hinzufügen** → Adresse **`mc.grahl.cloud`** → beitreten.
4. Beim ersten Beitritt fragt das Spiel nach dem **Server-Resourcepack**: **Ja** wählen. Das Pack ist **Pflicht**, weil es die deutschen Questbuch-Texte und die Weihnachts-Optik enthält. Wer ablehnt, wird getrennt und kann es beim nächsten Versuch annehmen. Das Pack lädt einmalig rund 10 MB.

## Was geht

- Alles am Spiel selbst: Hub, Kisten-Menü, Spielwelt, Weihnachtsinsel, Spenden, Händler, Winterkalender
- **Questbuch** mit Taste **L** (das normale Fortschritte-Fenster), auf Deutsch
- Die ganze Weihnachts-Optik aus dem Resourcepack: Deko, Mützen und Schals, Winterbilder, Weihnachtsmann-Händler

## Was fehlt (nur mit Modpack)

| Was | Hinweis |
|---|---|
| **Sprachchat** | Ohne Simple Voice Chat hörst du die anderen nicht und sie dich nicht. Tipp: Discord-Sprachkanal oder doch das Modpack |
| **Questbuch-Komfort** | kein großes Fenster, keine Seitenleiste mit Tipps, kein Buch-Knopf im Inventar |
| **Karte** | keine Minikarte, keine Weltkarte, keine Wegpunkte |
| **Weite Sicht** | nur deine normale Sichtweite statt der fernen Landschaft vom Server |
| **Flüssiger und schöner** | keine Leistungs-Mods (mehr FPS), keine Shader, kein Zoom, kein verbundenes Glas |
| **Komfort** | z. B. Rezeptsuche (JEI), Kisteninhalt im Tooltip, Sortieren, Lichtlevel-Anzeige |

Umsteigen geht jederzeit: Modpack installieren (`ANLEITUNG.md`), gleiche Adresse, deine Welt und Sachen bleiben.
