# Mods im optionalen Pack

Alle Mods sind reine Client-Mods ohne Spielvorteil. Wer das Pack nicht nutzt, spielt mit normalem Minecraft genauso mit.

| Mod | Zweck | Warum kein Spielvorteil |
|---|---|---|
| Fabric API | Grundlage für die anderen Mods | – |
| Sodium | mehr FPS | nur Grafik-Leistung |
| Lithium | flüssigere Spiellogik im Einzelspieler/Client | ändert keine Spielregeln |
| Entity Culling | mehr FPS, unsichtbare Objekte werden nicht gezeichnet | nur Leistung |
| Iris | Shader | nur Optik |
| Xaero's Minimap | Minikarte, Wegpunkte | Höhlenansicht und Entity-Radar sperrt der Server (Plugin „Fair Play for Xaero's Maps“) |
| Mod Menu | Mod-Einstellungen im Menü | – |
| Zoomify | Zoom-Taste | entspricht einem Fernrohr |
| YACL, Fabric Language Kotlin, Placeholder API | automatisch mitinstallierte Abhängigkeiten | – |

Aktuelle Dateien und Versionen: `STAND.md` (wird von `node tools/modpack.mjs` geschrieben).
