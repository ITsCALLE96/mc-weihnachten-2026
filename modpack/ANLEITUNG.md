# Optionales Modpack installieren (5 Schritte)

Du brauchst das nicht zum Mitspielen – es macht Minecraft flüssiger und schöner und bringt Karte, Shader und viele Komfort-Funktionen.

1. **Modrinth App** herunterladen und installieren: https://modrinth.com/app
2. Die Datei **`weihnachten-modpack.mrpack`** herunterladen: https://github.com/ITsCALLE96/mc-weihnachten-2026/releases/tag/modpack-v2
3. In der Modrinth App oben links auf **„+“ → „Aus Datei importieren“** und die `.mrpack`-Datei auswählen. Die App lädt alles selbst herunter.
4. Mit deinem Microsoft-Konto anmelden und das Profil **„Weihnachtsprojekt 2026“** mit **Play** starten.
5. **Mehrspieler → Server hinzufügen → Adresse `mc.grahl.cloud`**. Beim Beitreten das Weihnachts-Resourcepack annehmen.

## Nützliche Tasten und Schalter

| Was | Wie |
|---|---|
| Shader an/aus | **Optionen → Videoeinstellungen → Shader-Pakete** → „Complementary Reimagined“ |
| Hell sehen (Fullbright) | **H** = Nachtsicht, funktioniert auch mit Shadern · **G** = Helligkeit hoch, nur ohne Shader |
| Zoom | **C** gedrückt halten |
| Weltkarte | **M** |
| Wegpunkt setzen | **B** |
| Inventar sortieren | **Mausrad-Klick** im Inventar |

Die Tasten lassen sich unter **Optionen → Steuerung** ändern (mit Suchfeld).

## Weite Sicht

- **Bobby** merkt sich jeden Chunk, den du gesehen hast. Du siehst also weiter, als der Server schickt. Läuft von allein.
- **Distant Horizons** zeigt Berge und Landschaft bis zum Horizont in vereinfachter Form. Das braucht etwas Leistung. Bei einem schwachen Rechner: **Mods → Distant Horizons → Einstellungen** und das Rendern ausschalten.
