# Mit Bedrock mitspielen (Handy, Tablet, Windows-Edition)

Bedrock-Spieler kommen über einen Übersetzer (Geyser) auf denselben Server wie die Java-Spieler. Ihr spielt in derselben Welt mit allen anderen, bekommt aber ein kleineres Spiel. Was fehlt, steht unten.

## So kommst du rein (3 Schritte)

1. **Im Discord anmelden:** im Anmelde-Kanal auf den Knopf drücken und **Edition: Bedrock** wählen. Als Namen deinen **Xbox-Gamertag** eintragen, genau so geschrieben wie im Spiel. Erst danach stehst du auf der Whitelist.
2. **Minecraft aktuell halten:** Bedrock immer auf die neueste Version updaten. Mit einer alten Version klappt der Beitritt nicht.
3. **Server hinzufügen:** Spielen → **Server** → **Server hinzufügen**
   - Name: Weihnachtsprojekt
   - Adresse: **`mc.grahl.cloud`**
   - Port: **19132**

   Speichern, antippen, beitreten.

Im Spiel steht vor deinem Namen ein Punkt (z. B. `.Gamertag`). So erkennt der Server Bedrock-Spieler, das ist normal.

**PlayStation, Xbox, Switch:** Konsolen können keine eigenen Server eintragen. Es gibt einen Umweg über eine geänderte DNS-Einstellung an der Konsole, der hat aber Nachteile beim Datenschutz. Frag bei Interesse im Discord nach, das entscheidet jeder (bzw. die Eltern) selbst.

## Was geht

- Ganz normal spielen: bauen, abbauen, handeln, kämpfen, in derselben Welt wie die Java-Spieler
- Hub mit dem Kisten-Menü (Kiste lange antippen) und der Wechsel zur Spielwelt, mit `/hub` zurück
- Chat mit allen, Leitfaden-Texte, Titel und Ansagen
- Weihnachtsinsel, Spenden, Händler, Winterkalender
- Fortschritte bzw. Questbuch als einfache Liste: Befehl **`/geyser advancements`**, deutsch

## Was dir fehlt

| Was | Warum |
|---|---|
| **Sprachchat** | Simple Voice Chat gibt es nur für Java. Du hörst die anderen nicht und sie dich nicht. Tipp: nebenher Discord-Sprachkanal |
| **Questbuch-Fenster mit Detailseite** | Das große Fenster und die Seitenleiste mit Tipps sind Java-Mods. Du hast nur die einfache Liste (siehe oben) |
| **Karte** (Minikarte, Weltkarte, Wegpunkte) | Java-Mod (Xaero). Bedrock hat nur die normale Karte zum Herstellen |
| **Weite Sicht** | Die ferne Landschaft vom Server ist eine Java-Mod. Du siehst nur deine normale Sichtweite |
| **Weihnachts-Optik** | Das Weihnachts-Resourcepack gibt es nur für Java. Deko, Mützen, Winterbilder, Weihnachtsmann-Händler siehst du als normale Gegenstände bzw. Vanilla-Aussehen (z. B. Papier statt Deko-Kugel) |
| **Shader, Zoom, Komfort-Mods** | alles Java-Mods |

Spielvorteile hat dadurch niemand: Was die Java-Spieler extra haben, ist Optik und Komfort.
