# LuckPerms-Gruppen fürs Weihnachtsprojekt (Plan: server/namen-clans-grief.md). Ein Befehl je Zeile, einmal auf einem Server ausführen
# (gemeinsamer Speicher, der andere lädt per watch-files nach). Testnetz: bash testnetz/namen-test.sh gruppen. VM200: AMP-Konsole des SMP.
# spieler = default (alle), Rechte für alle kommen aus den Plugins selbst (serverwahl.nick, serverwahl.hub, weihnachten.spieler)
# Simple Voice Chat 2.6.x (Testrunde 30.10.: „keine Berechtigung“): plugin.yml legt listen/speak/groups ohne default an = nur Op → für alle freigeben
lp group default permission set voicechat.listen true
lp group default permission set voicechat.speak true
lp group default permission set voicechat.groups true
lp creategroup moderator
lp creategroup admin
lp group moderator parent add default
# Grief-Tool Prism (Pascal 28.10.): prism.lookup = Abfragen, /pr near, Teleport, Inspektor (auch unser Prüfwerkzeug Holzspitzhacke)
lp group moderator permission set prism.lookup true
lp group moderator permission set serverwahl.nick.andere true
# Moderation (Leitung 30.10.): kick, Bann und Entbannen (Vanilla kennt keinen Zeitbann: Moderator sperrt, hebt nach Absprache mit pardon wieder auf),
# Grim-Meldungen. Kein Op, kein luckperms.*
lp group moderator permission set minecraft.command.kick true
lp group moderator permission set minecraft.command.ban true
lp group moderator permission set minecraft.command.pardon true
lp group moderator permission set minecraft.command.banlist true
lp group moderator permission set grim.alerts true
lp group moderator permission set grim.alerts.enable-on-join true
# Rollback/Restore/Purge nur admin. Bewusst kein „*“: das würde auch Ausnahmen wie grim.exempt verteilen
lp group admin parent add moderator
lp group admin permission set prism.modify true
lp group admin permission set prism.purge true
lp group admin permission set luckperms.* true
lp group admin permission set serverwahl.admin true
lp group admin permission set minecraft.command.ban-ip true
lp group admin permission set minecraft.command.pardon-ip true
lp group admin permission set grim.verbose true
# Moderatoren: vorerst keine (Pascal 30.10.), Gruppe moderator existiert ohne Mitglieder. Später: lp user <Name> parent add moderator
lp user ITsCALLE96 parent add admin
